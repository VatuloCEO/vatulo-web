Brand

The symbol and the wordmark.

They used to be one thing — the name, set in a gradient, standing in for a logo everywhere. That works until something needs a mark with no room for six letters, which is exactly what an app header is. So they are two pieces now, with one rule for which goes where.

01 — the symbol

A V with a dot over it.

It reads as the letter first. Then, a second later, as somebody with their arms in the air — the head between two raised arms. Both readings are meant to be there, in that order.

The mark. Two strokes and a circle — nothing else to lose.

As the app icon, on the near-black ground the stores round for you.

Down to 16px, where a tab bar or a favicon would use it. The gap between the dot and the arms is what keeps it from closing up.

One colour, for the places the gradient cannot go — an Android monochrome icon, a notification glyph, anything printed.

02 — the wordmark

vatulo, lowercase, always.

Set in Quicksand: rounded terminals, a single-storey a, a geometric skeleton that stays friendly rather than turning corporate. Inter sets every other word on this site — a wordmark in the same neutral grotesque as the body copy is not a wordmark, it is a heading.

03 — the lockup

Both, when the name still needs saying.

The exception rather than the default. Use it where somebody is meeting Vatulo for the first time and the mark alone would not tell them anything — a website nav, a splash screen, a slide.

Horizontal. The symbol is set 16% taller than the letters beside it — optically, not literally: a round mark matched exactly to a cap height always looks the smaller of the two.

04 — in place

Where each one goes.

The difference is whether the viewer already knows what Vatulo is. In the app they downloaded, they do — so the header spends nothing on the name. On the web they might not, so the nav says both.

App header — symbol only. The tab bar underneath already names the screen. A logo that repeats its own name on every screen of an app you have already installed is spending the most valuable strip of the layout on a question the user settled weeks ago.

The short version

Do

  • App header, tab bars, favicons, app icons, notification glyphs: symbol alone.
  • Splash, marketing pages, decks, anywhere the name has to be readable: wordmark.
  • Website nav, first-contact surfaces: lockup.
  • Keep the wordmark lowercase. Vatulo is the company in a sentence; vatulo is the logo.
  • Use the flat one-colour symbol wherever the gradient cannot render.

Don't

  • Put the wordmark in the app header. That is the whole reason these were split.
  • Set the wordmark in Inter, or the interface in Quicksand. One face, one job.
  • Re-space the lockup by hand — it is defined once in .brand and in Lockup.
  • Recolour the symbol to a single brand colour. Either the full gradient, or a neutral.
  • Add a stroke, a shadow or a container around the mark. It has its own silhouette.
